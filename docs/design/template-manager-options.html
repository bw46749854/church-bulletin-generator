選んだもの: 案 C

  • 色をその場で選べる（案 A は背景.json を手で直して差し替える。色コードの打ち間違いが起きやすい）。見本のスライドで、読めるかをその場で確かめられる。
  • 部品ごとに「どの礼拝で使っているか」が見えるので、差し替える前に影響する所が分かる（設計の「影響範囲を閉じる」の確かめが画面でできる）。使っていない部品だけ削除できる。
  • 案 B は式順が中心で分かりやすいが、同じ部品が何度も出てくる（賛美・聖句・黙祷）ので、部品の差し替えがどの礼拝に効くかが逆に見えにくい。式順の並べ替えまで画面で作ると大きくなる（いまは JSON の差し替えで足りる）。
