# 触ってよい範囲（区分）

2026-09-23。目的は**属人性の解消**（`requirements-todo.md` 項目 9）。
非エンジニアが AI に改修を頼める状態にするとき、「何を任せ、何を止めるか」の基準。

## 分け方の軸

致命度ではなく、**戻せるか・気づけるか**で分ける。

```
被害が大きい × すぐ気づく   → 実はそれほど危なくない（戻せる）
被害が小さい × 気づかない   → じわじわ効く
被害が大きい × 気づかない   → ★ここが本当に危険
```

レイアウトが崩れるのは派手だが、誰でも気づいて戻せる。
名簿が公開ページに出るのは、誰も気づかないまま検索に載る。同じ「壊れた」でも意味が違う。

## 🟢 緑 — 自由に触ってよい

壊れたら誰でも気づき、1 操作で戻せる。プレビューで見える。

| パス | 中身 |
|---|---|
| `website/src/pages/*.astro` | 各ページの本文（13 ページ） |
| `website/src/layouts/` `website/src/components/` | 見た目 |
| `website/public/images/` | 写真 |
| `shuho/src/template/bulletin.css` | 週報の紙面デザイン |

## 🟡 黄 — PR は出すが、影響の説明と確認手順を添えさせる

戻せるが、気づくのが遅れる。

| パス | なぜ気づきにくいか |
|---|---|
| `shuho/src/template/render.js` | 紙面の組み立て。条件によってしか出ない崩れがある |
| `shuho/src/template/fit-policy.json` | 文字の縮小規則。**長い説教題の週に初めて崩れる** |
| `shuho/src/admin/` `shuho/src/ui/` `shuho/src/slides-page/` | 入力画面・担当者ページ（ui/ は共通の部品）。特定の操作でしか踏まない |
| `shuho/src/lib/bible.mjs` | 聖書箇所の解釈。特定の書名・範囲でしか出ない |
| `website/src/site.ts` `website/astro.config.mjs` | ビルドは通るが結果が変わることがある |

黄では「**どの週・どの入力で確かめるべきか**」を添えさせる。

## 🔴 赤 — 触らせない（PR を作らない）

戻せない、外に漏れる、または請求が発生する。

| パス | 壊れると何が起きるか |
|---|---|
| `shuho/src/lib/auth*.mjs`、`shuho/worker/index.mjs` の `publicPaths` | **名簿が公開ページに出る。誰も気づかないまま検索に載る** |
| `shuho/src/lib/api.mjs` のデータ書き込み（`store.put` / `history` 退避 / `validateObject`） | **実データが消える。退避が飛べば戻せない** |
| `shuho/wrangler.jsonc`、`website/wrangler.jsonc`、`render.yaml`、`render/Dockerfile` | **配置が壊れ、直す手段そのものを失う** |
| `shuho/worker/pdf.mjs`（Browser Rendering の呼び出し） | **無料枠を超えて請求が発生する** |
| 環境変数・シークレットを扱う箇所 | 合言葉が漏れる |
| `package.json` `package-lock.json`（依存の追加） | 見えないコードが入る |
| `shuho/ops/`、`.claude/` | 防御そのものが外れる |

共通点は「**気づけない**」か「**戻せない**」。緑がどれだけ派手に壊れても、この 7 つより安全。

## 運用の決まり

- **赤は機械的に止める**（PR を作るコードがファイルを弾く）。説明で押し切れないようにする。
  ただし**なぜ触れないか・何が依存しているかは説明させる**。止めるだけだと「なぜダメか分からない」＝ブラックボックスが復活する。
  **止めるのは機械、教えるのは AI。**
- **判定は要求の文面ではなく、生成された差分で行う。**
  「トップページを少し直して」という無害な依頼から赤のファイルを触るパッチが出ることがある。
  ① 要求を読んで事前に警告（親切）→ ② パッチを作る → ③ **差分を検査して赤が 1 つでもあれば PR を作らない（本番の防御）**
- **依存関係は人が書いて保存する。AI に推測させない**（もっともらしい嘘を言う）。
  出典は `docs/ARCHITECTURE.md`。AI はそこから引用するだけにする。
